# Диаграммы

Автономные SVG: литеральные цвета как presentation-атрибуты + `@media (prefers-color-scheme)`
для тёмной темы. Открываются в браузере и читаются в обеих темах GitHub; если рендерер вырежет
`<style>`, останется корректная светлая версия.

Исходник и подписи к схемам — в артефакте
[Архитектура FlowForge](https://claude.ai/code/artifact/f8a46d28-a5a3-4de2-9917-e95ae4e81137).

## Единая нотация

| Элемент | Значение |
|---------|----------|
| Сплошная стрелка, синий | Синхронный вызов (HTTP) |
| Пунктирная стрелка, охра | Сообщение через RabbitMQ |
| Двусторонняя стрелка | Обмен в обе стороны (команда вниз, результат вверх) |
| Пунктирная рамка блока | Не отдельный контекст: делит код и БД с другим сервисом |
| Чип внизу блока | БД, которой владеет сервис |
| Жирная рамка | Компонент, вокруг которого построено решение |

## Схемы

### [`01-service-topology.svg`](01-service-topology.svg)
Девять деплоев, кто с кем говорит синхронно, а кто через брокер, и какая БД кому принадлежит.
Границу control/data plane пересекают только сообщения: ни один воркер не пишет в
`execution_db`.
→ [ADR-002](../adr/002-microservices-boundaries.md), [ADR-011](../adr/011-workflow-version-snapshot.md)

### [`02-service-internals.svg`](02-service-internals.svg)
Слои `execution-service`. Смысл в направлении стрелок снизу: порты объявлены в домене,
инфраструктура их реализует — зависимость инвертирована, `domain/` тестируется без Postgres.
→ ADR-001

### [`03-node-result-path.svg`](03-node-result-path.svg)
Путь одного результата ноды. Порядок `COMMIT → ACK → PUBLISH` и три сбоя, закрытые тремя
разными механизмами: UNIQUE на `event_id`, redelivery, reaper по истёкшему lease.
→ [ADR-012](../adr/012-execution-consistency.md), ADR-006, ADR-007

## Правка

Схемы рисованные, без исходников в редакторе — правятся как текст (координаты выровнены по
сетке, шаг 10). При изменении палитры менять и presentation-атрибуты, и блок `@media` в
`<style>`: значения дублируются намеренно, ради устойчивости к вырезанию стилей.
